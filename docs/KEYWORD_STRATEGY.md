# Keyword Strategy — Creating the Space

> The estate is not competing in an existing category. It is defining a new
> one: **AI operator evaluation** — measuring how effectively humans operate
> AI systems, using content-free token telemetry.
>
> No one searches for "AI operator evaluation" yet. That's the point. We
> create the vocabulary, publish the definitions, build the comparison pages,
> and let the search demand follow. This document maps the proprietary
> vocabulary, the existing demand we can capture, and the funnel structure
> that turns awareness into traffic into signups.

---

## 1. The Space We're Creating

### The category gap

| Existing category | Who owns it | What they measure | What they miss |
|---|---|---|---|
| AI skills assessment | Workera | Demonstrated capability via tests | Actual operator performance |
| AI usage analytics | Worklytics | Adoption counts, activity volume | Efficiency, quality, operator skill |
| AI token tracking | ccusage, tokscale, TokenTracker | Token volume and cost | What the tokens *mean* — yield, efficiency |
| AI agent evaluation | Galileo, Arize, Braintrust | Agent/model quality | The human operating the agent |
| Workforce analytics | Weave, Paxel | Engineering output, workflow patterns | Operator-level measurement |

**The gap:** No one measures the *operator* — the human driving the AI.
That's the space. The vocabulary below defines it.

### The positioning axis

```
Assessment ←─────────────────────────────────→ Measurement
(Workera)           (gap)                        (MO§ES / SigRank)

  "Can you do this?"                    "How do you actually do this?"
  Scenario-based tests                  Content-free token telemetry
  Capability score                      Performance profile
  Point-in-time snapshot                Continuous, benchmarked
```
